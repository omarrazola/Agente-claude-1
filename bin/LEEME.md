# Binarios y herramientas

Para ejecutar `iniciar-tunel.bat`, descarga el ejecutable oficial de Cloudflare Tunnel (`cloudflared.exe`) para Windows y colócalo en este directorio:

- Descarga directa: https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
- Renómbralo a: `cloudflared.exe`
